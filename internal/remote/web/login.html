Install Quarters on this tablet or phone

Android's Chrome installs apps only from secure addresses, and this one is plain HTTP (your home network). Tell Chrome to trust this one address, once:

  1. Open chrome://flags/#unsafely-treat-insecure-origin-as-secure in a new tab (type or paste it).
  2. In the box, enter
  3. Set it to Enabled, then tap Relaunch.
  4. Come back here, sign in, and choose ⋮ → Install app (or Add to home screen → Install).

Face ID, Touch ID or your device PIN unlocks your passkey.
